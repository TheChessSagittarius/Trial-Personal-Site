# Personal Portfolio Website

A personal website + portfolio built to showcase my background, skills, and projects

## Features
- **About Me:** Quick intro / overview of education and hobbies
- **Projects Section:** Simple Layout displaying the hardware + software projects I've made. Projects include Water reminding Coaster, AI Garbage Sorter, and a python script compiling chess.com stats through its public API (Also for Stardance Challenge)
- **Skills and Tech Stack:** Brief list of languages, tools used, and skills
- **Experience / Education** More detailed info on secondary + post-secondary plans / education. Extracurricular and academic achievements

## Process
- Understanding general structure of html web development through Stardance guide
- Fleshed out sections I wanted to include and used basic header, paragraph or unordered lists to create the content
- Used CSS to make slight changes to formatting and colouring to make it look a bit better
## Things Learned
Helped me understand HTML and CSS integration with web development. I've become more versed in them and got experience using Github Pages.
